# Omnissiah Breakwall — описание проекта

Omnissiah Breakwall — портативный лаунчер WinForms для Windows 10/11 x64. Тестовая сборка 1.4.0 формирует один набор правил для zapret `winws` 72.9 и при необходимости подключает Cloudflare WARP. [История опубликованных релизов](https://github.com/a1deus/Omnissiah-Breakwall/releases)

| Файл | Ответственность |
| --- | --- |
| [src/Program.cs](../src/Program.cs) | Экран стратегий, сохранение выбора и перенос прежних ID, запуск, отмена, трей и встроенная инструкция. |
| [src/Engine.cs](../src/Engine.cs) | Аргументы, порядок правил и жизненный цикл winws. |
| [src/DsStrategy.cs](../src/DsStrategy.cs) и [profiles/ds-strategies.args](../profiles/ds-strategies.args) | Сохранённые рецепты Flowseal для Discord и YouTube. При сборке каталог встраивается в EXE. |
| [src/Warp.cs](../src/Warp.cs) | Официальный Cloudflare WARP или встроенный usque, регистрация, маршруты, запуск и остановка. |
| [src/ReleaseUpdate.cs](../src/ReleaseUpdate.cs) и [src/WindowsStartup.cs](../src/WindowsStartup.cs) | Обновление через GitHub Releases, проверка архива и автозапуск через Планировщик Windows. |

## Как применяются правила

- `Engine.Arguments` собирает диапазоны WinDivert и упорядоченные профили `--new`. Первый подходящий профиль выигрывает. Списки хостов включают поддомены, а префикс `^` задаёт точное совпадение. Имена в бинарных шаблонах относятся к содержимому подставного пакета. Адрес назначения берётся из исходного потока.
- При включении SM вместе с Discord распознанный Discord/STUN на UDP `50000–50100` проверяется до игрового правила. Эти порты попадают в захват через диапазон SM `48800–55000`.
- Настройки хранятся в `%LOCALAPPDATA%\Omnissiah Breakwall\strategies.txt`. Видимые коды и ID в файле — разные значения. `Restore` также принимает прежние ID удалённых игровых вариантов. При неизвестном ID остаётся начальный выбор группы. У Space Marine 2 начальный выбор — «Выключено», а у Darktide, Discord, YouTube и WARP — основной профиль.
- Галочка WARP управляет туннелем, а W01–W03 задают внешние правила winws для подключения. При другом активном VPN запуск нового туннеля пропускается. Встроенный usque пробует MASQUE через QUIC, затем HTTP/2 по TCP. Регистрация хранится в профиле Windows под DPAPI. Правила WARP не описывают трафик внутри туннеля.

## Игровые замеры

- **Darktide.** Игровой UDP `35500–35650,35670` по портам. Последние 30 логов от 14–20 ноября 2026 содержат 119 упоминаний игровых адресов в диапазоне `35500–35650` и запросы HTTPS к discovery и авторизации. Порт `35670` подтверждён в логах от 7 и 8 ноября. Источник — `%APPDATA%\Fatshark\Darktide\console_logs`. Доменные правила HTTP, TLS и QUIC общие для всех DT. В логах отсутствуют выбранный профиль, данные пакетов и статус фильтра.
- **Space Marine 2.** UDP `48800–55000` и TCP `11700–11720` используют общий IP-список и отдельные списки UDP/TCP. В замере миссии внешний поток `170.23.153.205:48873` дал 5 125 исходящих и 1 721 входящее событие ETW через Amnezia. В хабе основной UDP шёл по loopback. В снимках сокетов видны установленные внешние TCP-соединения на `11701/11702`. Протокол на этих портах снимки определить не позволяют. Для TCP сохранён один базовый TLS-профиль.
- Исходные файлы SM2 — `game-udp-flows.csv` и `game-sockets.csv` в каталогах `SM2-network-20261116-184453` и `SM2-live-hub-20261116-185920` внутри `%USERPROFILE%\OneDrive\Documents\New project`. При проверке новых профилей измеряйте вход в хаб, вход в миссию и удержание сессии отдельно.

## Соответствие стратегий

Имя BAT показывает источник или близкий исторический аналог. В EXE используются адаптированные параметры и списки Breakwall. Пункт «Выключено» есть у каждой группы.

### Darktide и Space Marine 2

Одинаковые номера DT и SM используют один рецепт игрового UDP на разных портах и адресах. Доменные правила игровых сервисов фиксированы. `DT02` восстанавливает альтернативный TLS из 1.3.0 для встроенных стратегий Discord. Он применяется к общим доменам Discord на TCP `443` и к запасному правилу `discord.media` на дополнительных TCP-портах. У `DS02–DS07` специальные правила по-прежнему имеют приоритет. Порог `nN` в winws исключает пакет с номером N.

## Сборка и проверки

Из корня проекта запустите `.\src\build.ps1 -Version 1.4.0`. Скрипт использует компилятор .NET Framework x64 и обновляет EXE. `winws --dry-run` проверяет аргументы, шаблоны и списки и завершает работу до запуска перехвата. Живые проверки должны измерять вход и стабильность сессии отдельно для каждого сервиса. Общий веб-тест Flowseal не измеряет игровой UDP.
