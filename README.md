# Omnissiah Breakwall 1.4.0

Переносимый лаунчер для Windows 10/11 x64 с профилями zapret для Warhammer 40,000: Darktide, Space Marine 2, Discord и YouTube и автоматическим выбором клиента Cloudflare WARP. Пошаговый запуск описан в [Инструкция.txt](./Инструкция.txt).

[Скачать готовую сборку для Windows](https://github.com/a1deus/Omnissiah-Breakwall/releases/latest)

## Code signing policy

На данный момент релизные сборки лаунчера Omnissiah Breakwall публикуются без цифровой подписи. Готовые сборки и история версий доступны на [странице релизов](https://github.com/a1deus/Omnissiah-Breakwall/releases).

## Privacy

Лаунчер хранит выбранные стратегии и состояние галочки WARP локально в профиле Windows. Лаунчер не отправляет эти настройки или диагностические отчёты разработчику.

При нажатии **Проверить обновления** лаунчер запрашивает сведения о последнем релизе у GitHub. Если пользователь подтверждает установку, он скачивает архив из GitHub Releases. GitHub получает IP соединения и обычные данные HTTP-запроса. [Политика конфиденциальности GitHub](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)

Если пользователь включает WARP, клиент связывается с Cloudflare для подключения, а трафик, направленный в туннель, проходит через сеть Cloudflare. При первой регистрации встроенного клиента Cloudflare получает IP соединения и данные для регистрации устройства. Регистрационные данные встроенного WARP хранятся в профиле Windows в зашифрованном виде. При использовании официального клиента данные хранятся у него. [Политика конфиденциальности Cloudflare WARP](https://developers.cloudflare.com/warp-client/privacy/)

## Стратегии

Если уже запущен другой zapret, завершите его через его собственный интерфейс перед включением этой сборки. Для проверки входа в Darktide выберите **DT01**, оставьте WARP выключенным и попробуйте войти в «Моурнингстар». При повторении ошибки 2004, 2014, 3001 или 3013 остановите фильтр, выберите **DT02** и повторите вход. Этот вариант усиливает обработку игрового UDP в начале сессии.

На главном экране нажмите **Настройка стратегий**. В разделе **Игры** находятся Darktide и Space Marine 2, а в разделе **Сервисы** — Discord, YouTube и WARP. Выберите варианты, вернитесь на главный экран и нажмите **Включить**. Пункт **Выключено** отключает правила выбранной игры или сервиса. Чтобы изменить выбор, сначала остановите фильтр.

Во время подключения кольцо светится светло-серым. Нажмите **Подождите** ещё раз, чтобы отменить подключение. Пока фильтр или запущенный лаунчером WARP работает, кнопка **Настройка стратегий** и галочка **Подключить WARP** заблокированы.

Диапазоны кодов — **DT01–DT15**, **SM01–SM15**, **DS01–DS11**, **YT01–YT10** и **W01–W03**. [Соответствие кодов и исходных рецептов](Для%20ИИ/Описание%20проекта.md#соответствие-стратегий).

При первом запуске Darktide, Discord, YouTube и WARP используют основные стратегии, а правила Space Marine 2 выключены. Галочка **Подключить WARP** управляет подключением и применением выбранной стратегии WARP. Программа сохраняет выбор в `%LOCALAPPDATA%\Omnissiah Breakwall\strategies.txt`. Сохранённые варианты игр из 1.3.0 и ранней 1.4.0 сопоставляются с оставшимися схемами UDP. Для удалённых вариантов сервисов без соответствия используется основной профиль. Пункт **Выключено** сохраняется.

### Игры

Варианты Darktide и Space Marine 2 меняют обработку игрового UDP. Для обеих игр варианты **01–12** покрывают прежние схемы. Варианты **13–15** добавляют игровые UDP-рецепты из zapret2 с 6, 8 и 4 повторами соответственно. Проверяйте их по одному, сохраняя остальные настройки.

- **Darktide** использует игровой UDP на портах `35500–35650` и `35670`. Общие доменные правила обрабатывают HTTP, TLS и QUIC, включая HTTPS к Atoma и `login.shr-prod-identity.fatshark.services`.
- **Space Marine 2** использует игровой UDP на `48800–55000` и базовое TLS-правило на TCP `11700–11720`. Общий IP-список дополняется точными адресами, замеченными в игре, отдельно для UDP и TCP. На UDP-портах, которые пересекаются с Discord, правило распознанного Discord/STUN проверяется раньше игрового. Домены Focus, Saber, Easy Anti-Cheat, Epic Online Services и PROS из `profiles/space-marine-2.txt` обрабатываются отдельно на TCP и UDP `443`. [Сетевые требования Epic](https://dev.epicgames.com/docs/epic-online-services/firewall-considerations) · [PROS для Space Marine 2](https://prismray.io/rewards?title=Y2F61)

### Сервисы

- **Discord** сохраняет семь прежних веб-вариантов и три импорта с разными голосовыми правилами. Для проверки голосового подключения начните с **DS01**, затем сравните **DS08–DS10**. **DS11** применяет альтернативный TLS из 1.3.0 к доменам Discord, включая CDN изображений. Если раньше вы использовали этот профиль через **DT02**, выберите **DS11** в разделе **Сервисы**.
- **YouTube** сохраняет шесть прежних вариантов и четыре импорта с разными сочетаниями TLS и QUIC. Рецепты Discord и YouTube хранятся в `profiles/ds-strategies.args` и включаются в EXE при сборке.

## Запуск с Windows и фоновый режим

Шестерёнка в правом верхнем углу открывает настройки в том же окне.
Ссылка **Инструкция** в настройках открывает краткое руководство по функциям лаунчера. Ниже находится раздел **О приложении** со ссылками на проект и авторов источников.

- **Автозапуск с Windows** создаёт задание в Планировщике Windows для текущей учётной записи. Задание запускает лаунчер с правами администратора при входе в Windows. После переноса EXE включите автозапуск снова, чтобы обновить путь в задании.
- **Фоновый режим** скрывает окно при сворачивании или закрытии. Значок рядом с часами открывает окно и позволяет управлять фильтром. Чтобы остановить фильтр и завершить программу, выберите **Выход** в меню значка. При сочетании фонового режима с автозапуском лаунчер открывается в трее.
- **Включать фильтр при запуске с Windows** применяет сохранённые стратегии и настройку WARP при входе в Windows. Эта опция доступна при включённом автозапуске.

Перед удалением portable-папки выключите автозапуск в настройках и завершите программу.

## Обновления

В настройках нажмите **Проверить обновления**. Если найден более новый стабильный релиз, нажмите **Установить**. Лаунчер сверяет SHA-256 загруженного ZIP с контрольной суммой из GitHub Releases, останавливает фильтр и принадлежащее приложению подключение WARP, затем запускает обновлятор. В существующей папке заменяются изменившиеся файлы из архива. После подтверждения запуска новой версии обновлятор удаляет резервную копию. При ошибке он восстанавливает заменённые файлы и указывает путь к резервной копии.

При включении фильтра лаунчер готовит рабочую копию winws и WinDivert в `%LOCALAPPDATA%\Omnissiah Breakwall\engine`. Эта копия используется для запуска, а правила читаются из папки программы. Если Windows ещё удерживает `WinDivert64.sys`, загруженный прежней сборкой из папки программы, перезагрузите Windows перед ручной заменой этого файла или повтором обновления.

Для публикации используйте стабильный тег вида `v1.4.0` и один готовый архив для Windows x64, например `Omnissiah-Breakwall-v1.4.0-win-x64.zip`, в **Assets**. Перед упаковкой соберите EXE командой `.\src\build.ps1 -Version 1.4.0`. Скрипт запишет `1.4.0.0` в метаданные Windows. Контрольная сумма архива берётся из метаданных GitHub. [GitHub Releases API](https://docs.github.com/en/rest/releases/releases#get-the-latest-release)

## Cloudflare WARP


Встроенный WARP использует существующую регистрацию Omnissiah Darktide. Путь к локальным данным сохранён для совместимости.

В разделе **Настройка стратегий → Сервисы** выберите вариант WARP. Основная стратегия имеет код **W01**. Вернитесь на главный экран, отметьте **Подключить WARP** и нажмите **Включить**. Лаунчер применит выбранные правила и автоматически выберет клиент WARP. Результат подключения отображается под галочкой. Если подключение не удалось, остановите фильтр и попробуйте **W02** с дополнительными повторами QUIC для MASQUE или **W03** с альтернативной обработкой TLS на IP-адресах MASQUE. С вариантом **WARP · Выключено** галочка подключает туннель без правил zapret для WARP.

- Если установлен официальный клиент Cloudflare в стандартном каталоге Program Files, лаунчер использует уже активное подключение или запрашивает новое. Ошибка клиента доступна в «Подробностях».
- При отсутствии официального клиента запускается встроенный WARP. Для регистрации и подключения нужен интернет. При первой регистрации подтвердите условия Cloudflare. Туннель пробует MASQUE по QUIC, затем по TCP, и пропускает игровой UDP. Встроенный клиент использует [usque 4.2.1](https://github.com/Diniboy1123/usque/releases/tag/v4.2.1) и [Wintun 0.14.1](https://www.wintun.net/).

При обнаружении другого активного VPN, включая AmneziaVPN, лаунчер пропускает запуск нового туннеля. Кнопка **Выключить** и обычное закрытие окна останавливают фильтр и WARP, если его запустил лаунчер. Уже активное подключение официального клиента продолжает работать.

Регистрация встроенного WARP хранится в `%LOCALAPPDATA%\Omnissiah Darktide Local\warp-masque.dpapi`. Windows шифрует приватный ключ, токен, ID регистрации и назначенные туннелю IP для текущей учётной записи. При запуске usque временный JSON создаётся в подпапке `warp-runtime` и удаляется после попытки подключения. Остаток после аварийного завершения очищается при следующем запуске встроенного WARP. Если локального файла ещё нет, прежняя регистрация из «Документов» или старого каталога AppData переносится при следующем подключении. Официальный клиент хранит регистрацию в собственном каталоге.

При регистрации usque использует условную модель PC и сгенерированный идентификатор. Cloudflare видит исходный IP сетевого соединения. Папку программы можно передавать отдельно от данных регистрации.

## Профили

При ручном редактировании списков указывайте по одному домену или IP-адресу/подсети в формате CIDR на строку в соответствующем файле. Доменные записи охватывают поддомены. Чтобы применить изменения, перезапустите фильтр.

- Выбранная стратегия YouTube применяет отдельные правила TLS и QUIC к сайту, видеосерверам и CDN превью из `profiles/youtube-core.txt`. Список `profiles/youtube.txt` включает также региональные домены Google и домены сервисов из списка v2fly. Все записи из `list-google.txt` Flowseal покрыты, включая `stable.dl2.discordapp.net`, который обрабатывается профилем Discord. [Список Flowseal](https://github.com/Flowseal/zapret-discord-youtube/blob/2401b7a13837139b0265632464ba563dddbf80d8/lists/list-google.txt) · [Список Google и YouTube](https://github.com/v2fly/domain-list-community/blob/777d056afe68b2643c1ef15f80e7bde3dfa149b1/data/google)
- `profiles/darktide.txt` содержит доменные зоны игровых сервисов Atoma, официальные сайты Fatshark и адрес Vivox из журналов игры. Поддомены учитываются автоматически. Профиль обрабатывает HTTP, TLS и QUIC к этим доменам.
- `profiles/base.args` содержит общие доменные правила Darktide и Discord. Лаунчер подставляет доменные списки включённых групп. Отдельное правило начала сессии Darktide формируется для UDP `35500–35650` и `35670` в `src/Engine.cs`. Если провайдер блокирует сам IP или весь UDP-маршрут, может понадобиться WARP. [Руководство Steam](https://steamcommunity.com/sharedfiles/filedetails/?id=3759171917)
- `profiles/discord.txt` охватывает домены Discord из Flowseal, включая клиент, CDN и вложения, а также Klipy для GIF. Из v2fly добавлены `discord.tools` и точный адрес поддержки `hammerandchisel.ssl.zendesk.com`. Голосовой UDP обрабатывается по диапазонам портов и сигнатурам Discord/STUN из Flowseal. [Flowseal](https://github.com/Flowseal/zapret-discord-youtube/blob/2401b7a13837139b0265632464ba563dddbf80d8/lists/list-general.txt) · [v2fly](https://github.com/v2fly/domain-list-community/blob/777d056afe68b2643c1ef15f80e7bde3dfa149b1/data/discord)
- `profiles/warp.txt` содержит домены служб клиента, Cloudflare Access, Gateway, DNS 1.1.1.1 и сайта WARP. `profiles/warp-api.txt` содержит точные адреса API регистрации для TLS. Списки `warp-masque.txt` и `warp-wireguard.txt` задают подсети для туннеля. Варианты W02 и W03 меняют только соответствующее правило MASQUE. Во всех трёх вариантах используется общее правило WireGuard. [Cloudflare](https://developers.cloudflare.com/cloudflare-one/team-and-resources/devices/cloudflare-one-client/deployment/firewall/) · [Flowseal](https://github.com/Flowseal/zapret-discord-youtube/blob/main/lists/list-general.txt) · [Руководство Steam](https://steamcommunity.com/sharedfiles/filedetails/?id=3695068003)
