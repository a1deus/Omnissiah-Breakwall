# Omnissiah Breakwall 1.5.0

Переносимый лаунчер для Windows 10/11 x64 с профилями zapret2 для Warhammer 40,000: Darktide, Space Marine 2, Discord и YouTube и автоматическим выбором клиента Cloudflare WARP.

[Готовые сборки и история релизов](https://github.com/a1deus/Omnissiah-Breakwall/releases) · [Инструкция](./Инструкция.txt)

## Что изменилось в 1.5.0

Все стратегии используют **zapret2 / winws2 1.0.7**. Лаунчер запускает один процесс фильтра для выбранных игр и сервисов. Прежний `winws.exe`, код его запуска и старые файлы правил удалены. Существующие рецепты перенесены с сохранением ограничений по доменам, IP и портам и числа начальных UDP-пакетов, кроме явно описанных изменений Flowseal.

- Импорты Discord и YouTube обновлены по [Flowseal, коммит c756d2e от 27 ноября 2026](https://github.com/Flowseal/zapret-discord-youtube/tree/c756d2eabd2cb089138e350d567f9b1581ae0276). Перекрытие Sferum — 661 байт; HTTP, TLS и этапы голосового подключения разделены фильтрами payload. Голос EXP обрабатывает первые четыре исходящих пакета по новому upstream.
- Для каждой игры добавлены три UDP-варианта из актуальных BAT Flowseal: 10 повторов ACTIVE_GAME на первых четырёх пакетах; 14 повторов на первых трёх; QUIC 4PDA + ACTIVE_GAME по пять повторов на первых четырёх.
- Прежние игровые варианты 14 и 16 объединены: после перехода на один движок они одинаковы. Сохранённый ID варианта 16 восстанавливает вариант 14. Старые ID остальных стратегий и прежние алиасы сохраняются; DS11 принимает прежний ID `LegacyAlternateTls`.
- TCP-рецепты с `hostfakesplit` перенесены на реализацию zapret2, как в новом Flowseal. Прежний режим `altorder=1` не воспроизводится побайтно.
- У circular-рецептов раздельные ключи состояния для WARP, Discord, YouTube и каждой игры. Входящий TCP захватывается для определения неудачных соединений.

## Переход с 1.4.x

**Для прямого перехода на 1.5.0 скачайте ZIP вручную и распакуйте в новую папку.** Обновлятор 1.4.2/1.4.3 требует в архиве старый `engine/winws.exe` и прежние профили. Он отклонит новый состав пакета до установки; исправление в новом EXE не меняет уже запущенный старый обновлятор.

1. В прежней версии выключите автозапуск с Windows, если он включён, остановите фильтр и завершите приложение через «Выход» в трее.
2. Распакуйте **весь** ZIP 1.5.0 в новую папку и откройте новый EXE. Не смешивайте файлы разных версий.
3. Выбранные стратегии, настройки и регистрация WARP сохраняются в профиле Windows и подхватываются новой версией. Если вы вручную редактировали доменные/IP-списки, перенесите только свои записи в соответствующие новые списки.
4. При необходимости включите автозапуск в 1.5.0, чтобы задание указывало на новый EXE.
5. После проверки новой версии прежнюю portable-папку можно удалить. Удалять данные из AppData и повторно регистрировать WARP не требуется.

Автоматический переход без ручной распаковки возможен через отдельный промежуточный релиз 1.4.x с обновлённым обновлятором. Такой релиз должен быть подготовлен и опубликован отдельно.

Обновлятор **1.5.0** проверяет новую структуру zapret2 и обязательные Lua-файлы, шаблоны и профили. При последующих обновлениях он заменяет изменившиеся файлы, удаляет только явно перечисленные устаревшие файлы и восстанавливает заменённые и удалённые файлы при ошибке. Пользовательские файлы вне этого списка не удаляются.

## Стратегии игр

Доступны DT01–DT26 и SM01–SM26. По умолчанию Darktide использует DT01, Space Marine 2 выключена.

| Коды | Что меняется |
| --- | --- |
| 01–15 | Прежние варианты начального игрового UDP: STUN, ACTIVE_GAME, QUIC и их сочетания. |
| 16 | Sferum + ACTIVE_GAME, по 5 повторов, первые 4 пакета; прежний код 17. |
| 17 | ACTIVE_GAME, 12 повторов, первые 3 пакета; прежний код 18. |
| 18 | Короткий dbankcloud, 10 повторов на первом пакете; прежний код 19. |
| 19 | Минимальный ACTIVE_GAME, 2 повтора на первом пакете; прежний код 20. |
| 20 | TLS с малым перекрытием; прежний код 21. |
| 21 | TLS fakeddisorder + MD5; прежний код 22. |
| 22 | TLS с копией ClientHello; прежний код 23. |
| 23 | TLS с переключением двух схем; прежний код 24. |
| 24 | ACTIVE_GAME, 10 повторов, первые 4 пакета; новый Flowseal. |
| 25 | ACTIVE_GAME, 14 повторов, первые 3 пакета; UDP-часть ALT5 Flowseal. |
| 26 | QUIC 4PDA + ACTIVE_GAME, по 5 повторов, первые 4 пакета; новый EXP Flowseal. |

У вариантов 20–23 игровой UDP остаётся базовым: STUN на первом исходящем пакете. У варианта 25 заимствован только UDP-рецепт: исходный ALT5 помечен `NOT RECOMMENDED`, его TCP-часть не используется. Числа в таблице относятся к исходным исходящим пакетам соединения, а не к непрерывной отправке фейков во время всей игры.

Darktide: игровой UDP `35500–35650,35670`; доменные HTTP 80, TLS TCP 443 и QUIC UDP 443. Space Marine 2: UDP `48800–55000` в пределах общих и UDP IP-списков; TLS `11700–11720` в пределах общих и TCP IP-списков; TLS/QUIC 443 по доменному списку. При активном Discord распознанный голос Discord/STUN на пересекающихся портах `50000–50100` получает приоритет. Нераспознанный UDP не перехватывается голосовой стратегией, если включена Space Marine 2.

## Discord и YouTube

Discord: DS01–DS13. Для голоса начните с DS01, затем сравните DS08–DS10 с разными шаблонами и повторами. DS11 — альтернативный TLS, DS12 — копия ClientHello, DS13 — переключение TLS-схемы. Дополнительные TLS-порты `2053,2083,2087,2096,8443` ограничены `discord.media`; голосовые UDP-порты — `19294–19344,50000–50100`.

YouTube: YT01–YT12. Варианты YT07–YT10 используют обновлённые рецепты Flowseal, YT11 — circular, YT12 — перестановку частей TLS. Основные домены и CDN находятся в `profiles/youtube-core.txt`, дополнительные сервисы Google — в `profiles/youtube.txt`. При одновременно включённом Discord его домены исключаются из правил YouTube.

Каталог импортированных Flowseal-рецептов `profiles/ds-strategies.args` содержит только параметры zapret2 и встраивается в EXE при сборке. Для его изменения пересоберите EXE.

## Автоподбор

На главном экране под «Настройкой стратегий» находится кнопка **Автоподбор**. Остановите текущий фильтр, откройте эту страницу и отметьте Darktide, Space Marine 2, YouTube, Discord или WARP. Кнопка **Запустить подбор** доступна, если выбрана хотя бы одна группа. Группы проверяются отдельно; неотмеченные группы в проверочные правила не включаются.

Во время проверки отображаются процент и текущий код. Повторное нажатие останавливает подбор и закрывает принадлежащие ему подключения. После окончания или остановки выводятся прошедшие проверки варианты. Кнопка **Применить** сохраняет соответствующую стратегию в настройках, не меняет остальные группы и не запускает фильтр или туннель. После этого нажмите «Включить» на главном экране. При WARP галочка подключения управляется отдельно.

Проверка использует тот же `Engine.Start`, что обычный запуск: собственные порты, IP-списки, доменные ограничения и Lua-рецепты Breakwall. Широкий ipset-all из Flowseal не используется. Чужие процессы zapret и VPN не завершаются; при конфликте подбор не запускается или останавливается. Для HTTPS нужен системный `curl.exe`; его настройки и прокси отключены только для тестовых запросов, сертификаты проверяются. Для каждого запроса создаётся новое соединение. Для circular предусмотрены дополнительные попытки без перезапуска фильтра между ними.

| Группа | Что подтверждает успешный результат |
| --- | --- |
| Darktide | TLS-доступность backend/авторизации и два UDP-ответа хотя бы одного игрового узла на начальный запрос с новым случайным UUID. |
| Space Marine 2 | TLS/HTTPS-доступность сервисов Epic и CDN античита из игрового доменного профиля. |
| Discord | Ответ API, загрузку изображения с CDN и TLS-доступность Gateway. |
| YouTube | Ответ сайта, загрузку изображения и TLS-доступность Googlevideo. |
| WARP | Реальное подключение туннеля и ответ Cloudflare trace с `warp=on` или `warp=plus`. |

Для UDP Darktide адреса автоматически читаются только из строк подключения в недавних локальных логах игры. Если адресов нет, группа пропускается: запустите игру до попытки входа в хаб, закройте её и повторите подбор. Логи загружать или вводить IP не нужно. До четырёх адресов фиксируются в памяти на весь подбор; используются только публичные IPv4 и порты профиля Darktide. Логи, адреса, пакеты и результаты не записываются в папку программы и не отправляются разработчику. Игровые билеты и идентификатор аккаунта не используются.

UDP-ответ Darktide подтверждает обмен с конкретным узлом в момент проверки. Вход в хаб/матч, устойчивость всей сессии, UDP Space Marine 2, её дополнительные TLS-порты, голос Discord, видео и QUIC этим тестом **не подтверждаются**. Отсутствие UDP-ответа может означать недоступный сервер, фильтрацию или изменение протокола. Результат — список прошедших конкретные проверки. Если проверки прошли без стратегии, это отдельно указывается.

Результаты находятся в памяти до закрытия приложения; только нажатие «Применить» сохраняет выбранный ID в локальные настройки. Ответы с адресами из WARP trace, тела запросов и регистрационные данные в отчёт не записываются. При проверке сервисы видят IP подключения. Реальные сетевые испытания пользователю запускаются только кнопкой, при подготовке этой сборки сеть не измерялась.

## Cloudflare WARP

В разделе «Настройка стратегий → Сервисы» выберите W01–W08, затем отметьте «Подключить WARP» на главном экране. Все правила WARP, включая WireGuard, работают в общем winws2. W01 — основной вариант, W02 усиливает QUIC для MASQUE, W03 меняет TLS MASQUE, W04–W08 используют circular и двойные шаблоны из проекта kinlay0. При выбранном «WARP · Выключено» галочка подключает туннель без правил обхода для WARP.

Если установлен официальный клиент Cloudflare в стандартном Program Files, используется он. Иначе запускается встроенный [usque 4.2.1](https://github.com/Diniboy1123/usque/releases/tag/v4.2.1) с [Wintun 0.14.1](https://www.wintun.net/). Автоматическая последовательность QUIC → HTTP/2 сохранена. При обнаружении другого активного VPN новый туннель не запускается. Уже активное подключение официального клиента не отключается при выходе из лаунчера.

Регистрация встроенного WARP хранится в `%LOCALAPPDATA%\Omnissiah Darktide Local\warp-masque.dpapi`, зашифрованная Windows для текущей учётной записи. Локальные ключи и регистрацию не включайте в релизный архив. Временный JSON usque удаляется после подключения; остатки после аварии очищаются при следующем запуске встроенного WARP.

## Настройки и работа в фоне

Настройки хранятся в `%LOCALAPPDATA%\Omnissiah Breakwall\strategies.txt`. Фоновый режим сворачивает приложение в трей; «Выход» завершает приложение и принадлежащий ему фильтр/туннель. Автозапуск создаёт задание Планировщика Windows для текущего пользователя. После переноса папки обновите путь, выключив и включив автозапуск.

Рабочая копия winws2, Cygwin и WinDivert подготавливается в `%LOCALAPPDATA%\Omnissiah Breakwall\engine` в каталоге, определяемом хэшами файлов. Профили и Lua читаются из папки приложения. При блокировке старого WinDivert-драйвера перезагрузите Windows перед заменой удерживаемого файла.

## Privacy и подпись

Лаунчер хранит настройки локально и не отправляет их или диагностические отчёты разработчику. При проверке и установке обновлений он обращается к GitHub; при подключении WARP — к Cloudflare. Эти сервисы получают IP соединения. Готовые сборки публикуются без цифровой подписи.
